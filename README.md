
# التطبيق: المدرسة الأكاديمية الخاصة

هذا مشروع Expo (React Native) بسيط كقالب أولي لتطبيق المدرسة. يمكنك بناء ملف APK من هذه الملفات باتباع الخطوات التالية.

## متطلبات
- Node.js مثبت (الإصدار 16+)
- npm أو yarn
- Expo CLI (اختياري) أو استخدام EAS لإنشاء APK موقّع
- Android Studio (لتشغيل على محاكي أو لبناء محلي)

## تشغيل التطبيق أثناء التطوير
1. فك الضغط وانتقل إلى مجلد المشروع.
2. نفّذ `npm install` أو `yarn`.
3. ثم `npx expo start` لتشغيل Metro Bundler وتشغيل التطبيق على جهازك.

## بناء APK (خيارات)
### 1) بناء APK باستخدام Expo Application Services (EAS) — موصى به
- قم بتثبيت EAS CLI: `npm install -g eas-cli`
- سجل دخول: `eas login`
- تهيئة المشروع: `eas build:configure`
- ثم شغّل: `eas build -p android --profile production`
هذا سيبني APK أو AAB على خوادم Expo وستتلقى رابط التحميل.

### 2) بناء محلي باستخدام Android Studio (مع `expo run:android`)
- افتح المشروع في Android Studio (قد تحتاج لتحويل إلى bare workflow).
- اتبع تعليمات Expo لتحويل المشروع إلى bare workflow: https://docs.expo.dev

## ملاحظات
- لا أستطيع إنشاء ملف APK هنا مباشرة، لكن أقدمت لك المشروع الجاهز. إذا رغبت، أستطيع مساعدتك خطوة بخطوة لبناء APK على جهازك أو استخدام EAS لإنشاءه.
- أخبرني إن أردت إضافات (تسجيل دخول، قاعدة بيانات محلية، مزامنة مع سيرفر المدرسة، إشعارات فورية، دعم اللغة الإنجليزية، إلخ.).
